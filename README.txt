GITHUB PAGES — FOR MY MI AMOR
=============================

This folder is ready to publish as a static GitHub Pages website.

IMPORTANT:
- Keep the folder structure exactly as it is.
- index.html must stay in the top level.
- The 8 MP4 files inside assets/video/ are intentional. GitHub limits individual files to 100 MB, so the original 10-minute video was split into 8 parts. The website plays them automatically as one continuous video.

EASIEST SETUP (PHONE OR COMPUTER)
---------------------------------
1. Sign in to GitHub.
2. Create a NEW repository. A cute name is: for-my-mi-amor
3. On the repository page, choose Add file -> Upload files.
4. Upload EVERYTHING INSIDE THIS FOLDER (not the folder itself):
   - index.html
   - .nojekyll
   - assets/poster.jpg
   - all 8 files inside assets/video/
5. Commit the files to the main branch.
6. Open Settings -> Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose Branch: main and Folder: / (root), then Save.
9. Wait a few minutes. GitHub will show a Visit site button on the Pages screen.

YOUR LINK WILL LOOK LIKE:
https://YOUR-USERNAME.github.io/for-my-mi-amor/

If your repository is named differently, replace for-my-mi-amor with that name.

PRIVACY NOTE:
GitHub Pages sites are public. Anyone who has the link can open the website. This package contains the birthday video, so only publish it if you are comfortable with that.
